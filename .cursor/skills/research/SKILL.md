# Research Skill (수집 레이어 SOP)

이 스킬은 "정보를 모으는" 레이어의 표준 작업 절차다. 판단·구현과 분리한다.

## 언제 쓰나

- 처음 쓰는 라이브러리/API의 정확한 사용법이 필요할 때
- "이 기능을 남들은 실제로 어떻게 구현했나" 예시가 필요할 때
- 개념·비교·최신 동향처럼 웹 리서치가 필요할 때

## 절차

1. **질문을 검증 가능한 형태로 쪼갠다.** ("좋은 라이브러리 뭐야?" → "X를 하는 데 쓰이는 라이브러리 후보 + 각 최신 사용법")
2. **도구 선택 (research 규칙 순서 따름)**
   - 공식 문서·정확한 API → **Context7** (`get-library-docs`)
   - 실제 코드 사용 예시 → **grep** (`searchGitHub`)
   - 넓은 웹·개념·비교 → **Exa** (`web_search_exa`)
3. **교차 검증.** 중요한 사실은 최소 2개 출처(문서 + 실제 코드)로 확인한다.
4. **정리한다.** 결론 먼저 → 근거 → 출처 링크. 미확인 항목은 명시.

## 산출물 형식

```
## 결론
- (핵심 답 1~3줄)

## 근거
- 주장 A — 출처: <링크/경로>
- 주장 B — 출처: <링크/경로>

## 미확인 / 주의
- (확인 못 한 것, 사람 판단 필요한 것)
```

## 경계선 (중요)

- 리서치는 **사실만** 모은다. "그래서 이 주제로 하자" 같은 **결정은 사람에게 넘긴다** (판단 레이어).
- 도구로 확인 가능한 것을 기억에 의존해 단정하지 않는다.
